### 🔑 Variáveis de Ambiente e Chaves

Para rodar a aplicação:

- **Chave de Administrador (ADMIN_SECRET):**
  Defina a variável `ADMIN_SECRET` no arquivo `.env` do backend com um valor seguro.
  **Para testes e acesso ao /admin no ambiente local, use o valor: `chave-secreta-do-admin-aqui`**
- **URL da API (NEXT_PUBLIC_API_BASE_URL):**
  Defina esta variável no `.env.local` do frontend, apontando para a porta do backend.
